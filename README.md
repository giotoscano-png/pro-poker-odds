# PRO Poker Odds Clean

Versione indipendente da Base44 della tua app poker odds.

## Cosa contiene

- Calcolatore odds Texas Hold'em con simulazione Monte Carlo
- Selezione carte personale e community cards
- Analisi outs dopo flop/turn
- Pagina Blackjack Trainer base
- Nessuna dipendenza da Base44
- Nessun componente UI proprietario Base44

## Come provarla gratis sul PC

1. Installa Node.js
2. Apri la cartella con VS Code
3. Apri il terminale nella cartella
4. Esegui:

```bash
npm install
npm run dev
```

5. Apri il link che compare nel terminale, di solito:
   http://localhost:5173

## Come pubblicarla gratis

Puoi pubblicarla come sito/web app su Vercel o Netlify.
